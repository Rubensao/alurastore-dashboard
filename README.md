# Dashboard AluraStore - Análisis de las Tiendas del Sr. Juan

Este proyecto presenta un **dashboard interactivo** desarrollado con **Streamlit**, cuyo objetivo es analizar el rendimiento de las 4 tiendas del Sr. Juan a partir de datos de ventas, productos, evaluaciones de clientes y costos logísticos. El propósito es ayudar a tomar una decisión sobre cuál tienda vender.

---

## Objetivo

Evaluar el desempeño de las tiendas con base en los siguientes indicadores clave:

- Facturación total
- Categorías más vendidas
- Calificación promedio de clientes
- Productos más y menos vendidos
- Costo promedio de envío

Después del análisis de datos, se recomienda vender la Tienda 4, ya que presenta el menor desempeño general en cuanto a facturación, calificación promedio y volumen de ventas, permitiendo optimizar recursos en las demás tiendas.
